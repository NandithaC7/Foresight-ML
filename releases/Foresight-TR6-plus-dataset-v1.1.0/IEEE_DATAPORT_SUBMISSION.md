# Remaining IEEE DataPort steps (manual)

This package has **not** been uploaded. No IEEE DataPort DOI exists.

1. Sign in at https://ieee-dataport.org (IEEE account).
2. Start **Submit a Dataset**.
3. Suggested title: `Foresight-TR6+: Provenance Manifests and Annotation Protocol for TriModal Ripeness 6`.
4. Dataset type: derived resource / supporting data. State clearly that original images remain at Figshare DOI `10.6084/m9.figshare.30783827.v1`.
5. Abstract: copy the Purpose and Scope sections of `README.md`.
6. Keywords: `computer vision`, `fruit inspection`, `thermal imaging`, `dataset provenance`, `duplicate detection`, `annotation protocol`, `TriModal Ripeness 6`.
7. Upload **only** `Foresight-TR6-plus-dataset-v1.0.0.zip` and the `.sha256` sidecar if DataPort accepts a checksum file. Do **not** upload `TR-6.zip` or any JPEG/PNG derived from TR-6.
8. Licence for this derived package: CC BY 4.0, with required attribution of the TR-6 authors.
9. In the description, paste the citation from `CITATION.md` and the blocked-content list from `NOT_INCLUDED.md`.
10. Add related-dataset / citation link to https://doi.org/10.6084/m9.figshare.30783827.v1.
11. Review the DataPort preview for absolute paths, credentials, or accidental image files.
12. Submit. Record the assigned DOI in `CITATION.md` after DataPort issues it. Do not invent a DOI beforehand.

Authors and affiliations on the DataPort form are yours to complete.
