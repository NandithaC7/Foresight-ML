# Foresight — final review package (15 October 2026)

This folder holds the documents for the academic review, technical demonstration and dataset publication.
Every number in the documents is generated by `build/build_reports.py` from saved logs, checkpoints and evaluation files (via `build/analysis.py` → `build/facts.json`).
Nothing is hand-entered. A result that does not exist is labelled **NOT RUN**, **NOT AVAILABLE**, **BLOCKED** or **SIMULATED**.

## Documents

| File | Contents |
|---|---|

  - `e2e_smoke.log` and `e2e_smoke_final.json`
  - `ui_contract_check.json`
  - `latency_benchmark.json`
  - `frontend_build.log`

## Status in one paragraph

A genuine ViT-B/16 classifier is trained on 5,335 de-duplicated TR-6 sRGB images, split 60/20/20 by capture session. On the untouched test split it reaches produce macro-F1 1.000 and spoilage macro-F1 0.954 (accuracy 0.961, ROC-AUC 0.989).
It is served by the FastAPI backend and used by the React UI for real inference. The TR-6+ package is prepared but **not uploaded**: no DOI exists, and authorship and the upload are your actions.

**BLOCKED or not implemented:**
- U-Net segmentation, because there are 0 reviewed masks
- shelf-life regression, because there are no labels
- YOLO detection, because there are no bounding boxes
- real-world photo evaluation
- third-party deployment
